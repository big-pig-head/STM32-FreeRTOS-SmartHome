# STM32-FreeRTOS-智能家居

基于STM32F103C8T6与FreeRTOS抢占式实时内核的智能家居控制系统，实现温湿度/信号采集、串口上位机交互、PWM电机调速、外部设置灯光与音频播放，自主设计三层任务优先级调度架构。

##系统架构

````
┌──────────────────────────────────────────────────────────┐
│ 三层优先级调度架构 │
├──────────────────────────────────────────────────────────┤
│ 采集层 (Prio 18) │ DHT11 温湿度采集 / BH1750 光源采集 │
│ 通信层 (Prio 17) │ 串口接收解析任务 (@CMD\r\n 协议) │
│ 执行层 (Prio 15) │ LED控制 / 风扇 PWM 调速 / 音乐播放 │
└──────────────────────────────────────────────────────────┘
````

##核心功能

-  **环境传感器**：DHT11 温湿度传感器、BH1750 I2C 卫星传感器，500ms 周期定时采集
- **上位机通信**：自定义 `@CMD\r\n` 串口协议，支持远程控制 LED、风扇、音乐
- **外设控制**：GPIO LED 灯光、TIM2 PWM 直流风扇调速、蜂鸣器音乐播放
- **任务调度**：FreeRTOS 抢占式调度，同优先级时间片轮转，互斥锁保护 OLED 共享资源

一、FreeRTOS 三层任务优先级调度架构
基于 FreeRTOS 抢占式实时内核设计三层任务优先级调度架构，分为采集层（Prio18）、通信层（Prio17）和执行层（Prio15），高优先级任务可抢占低优先级任务执行权，同优先级任务按时间片轮转调度。采集层负责温湿度与光照传感器数据采集，通信层负责串口指令接收与解析，执行层负责外设驱动控制。使用互斥锁保护 OLED 等共享资源，避免多任务并发访问导致数据冲突。该架构实现了任务间有序调度与资源安全共享，保障了系统的实时性与稳定性。

二、环境参数采集与监测
基于 DHT11 数字温湿度传感器实时采集室内温度与湿度数据，通过单总线协议完成数据读取与校验。同时通过 I2C 总线驱动 BH1750 光照传感器，每 500ms 读取一次环境光照强度，并据此自动控制室内灯光开关与亮度调节。采集的环境数据统一汇聚至 FreeRTOS 任务队列，由显示任务驱动 OLED 实时呈现温湿度与光照数值。该模块实现了室内环境参数的实时感知与可视化展示，为智能家居自动化控制提供数据基础。

三、本地按键中断控制
基于 GPIO 配置外部中断（EXTI）实现按键本地开关控制功能。当检测到按键触发时，通过中断服务函数快速响应，切换 LED 灯光、蜂鸣器等外设状态，无需依赖上位机指令即可完成本地操控。中断方式相比轮询查询大幅降低 CPU 占用，响应延迟控制在微秒级。该模块为用户提供了脱离上位机的独立操控入口，保障了通信断开场景下的基本控制能力。

四、PWM 多路外设驱动
使用 TIM 定时器生成多路 PWM 信号驱动不同外设：控制直流电机实现窗帘开合，驱动风扇实现通风调速，驱动舵机实现门禁动作，以及 PWM 驱动蜂鸣器实现音频输出与报警提示。通过调整 PWM 占空比实现风扇转速线性调节与电机方向控制，LED 灯光模块通过 GPIO 控制开关状态并与光照采集联动实现自动照明。该模块完整覆盖了嵌入式 PWM 调速与执行器驱动的核心开发能力。

五、OLED 多任务信息显示
通过 I2C 总线驱动 OLED 显示屏作为系统状态的统一信息展示窗口。由于多个 FreeRTOS 任务均需向 OLED 写入数据，系统使用互斥锁保护显示资源，确保同一时刻仅有一个任务获得写入权，避免并发写入导致显示错乱。OLED 实时展示温湿度、光照强度、设备开关状态及系统运行信息，构成人机交互的可视化界面。该模块解决了多任务环境下共享资源的并发访问问题，实现了信息的有序展示。

六、上位机串口远程交互
基于 USART 中断接收机制实现串口数据不丢帧接收，自定义 @CMD\r\n 指令协议完成指令帧定界与解析。搭配 Qt5 框架与 QSerialPort 模块开发 Windows 端可视化上位机，提供图形化界面发送控制指令并实时回显设备状态。上位机可远程控制 LED 灯光、风扇转速、蜂鸣器开关等外设，设备执行指令后通过串口回传当前状态，形成"指令解析→执行→反馈"的完整闭环。该模块实现了 PC 端对嵌入式终端的远程管控与状态监控。

## 技术栈

| 层级 | 技术 |
|------|------|
| 主控 | STM32F103C8T6 (ARM Cortex-M3, 72MHz) |
| RTOS | FreeRTOS V9.0 (抢占式调度) |
| 通信 | USART1 串口中断接收、I2C、单总线 |
| 驱动 | GPIO、TIM2 PWM、EXTI 外部中断 |
| 上位机 | Qt 5 + QSerialPort |
| 编译 | Keil MDK-ARM |

## 使用说明

1. **硬件连接**：按 `hardware/基于STM32F103C8T6的智能家居系统电路连接.pdf` 接线
2. **固件编译**：使用 Keil MDK 打开 `stm32_firmware/智能家居系统/Project.uvprojx` 编译烧录
3. **上位机运行**：直接运行 `qt_app/SmartHome-ByUart-V1.0/SmartHomeByUart.exe`，选择串口连接
4. **指令格式**：上位机发送 `@LEDON\r\n`、`@FengShanON\r\n` 等控制硬件
